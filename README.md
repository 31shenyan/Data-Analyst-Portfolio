## 项目列表

### 1. Olist 巴西电商综合运营分析与用户价值分层

基于 Kaggle 公开电商平台 Olist 订单数据（约 10 万条），使用 Python（Pandas）完成 9 张数据表的关联合并、缺失值处理与异常值过滤。运用 RFM 模型对 9.6 万用户进行价值分层，识别出高价值用户占比 6.5% 但贡献约 30% 消费额；构建 XGBoost 分类模型预测高价值用户，通过特征重要性分析发现用户评分与物流体验为关键影响因素。

**技术栈**: Python, Pandas, SQL, XGBoost, Tableau
**项目链接**: [01-olist-ecommerce/README.md](01-olist-ecommerce/README.md)

### 2. 电商 A/B 测试落地页转化率统计分析

基于电商公司落地页 A/B 测试数据（约 29 万条用户记录），使用 Python（Pandas）完成数据清洗，去除重复记录与不匹配样本。运用卡方检验、比例 z 检验、Odds Ratio 等方法对比新旧版落地页转化率差异，得出新版（11.87%）与旧版（12.03%）无统计学显著差异；进行事后功效分析，发现当前样本量仅为所需的 21.3%，统计功效仅 25.28%。

**技术栈**: Python, Pandas, SciPy, Matplotlib
**项目链接**: [02-ab-test-analysis/README.md](02-ab-test-analysis/README.md)
