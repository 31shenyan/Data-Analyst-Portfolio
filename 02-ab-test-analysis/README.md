# A/B 测试分析：落地页转化率对比研究

## 项目概述

本项目分析了一家电商公司进行的 A/B 测试结果，评估新版落地页相比旧版是否能提升用户转化率。

**数据来源**: [Kaggle - A/B Testing](https://www.kaggle.com/datasets/zhangluyuan/ab-testing)

---

## 业务背景

一家电商公司重新设计了落地页，并进行了为期 23 天的 A/B 测试（2017年1月2日 - 1月24日），以评估新设计是否能带来更高的转化率。核心问题：

> **公司应该上线新版落地页、保留旧版，还是继续测试？**

---

## 分析流程

### 1. 数据清洗 ([`ab_data_clean.ipynb`](python/ab_data_clean.ipynb))
- **去重**: 移除 3,894 条重复用户记录
- **对齐检查**: 移除 2,044 条分组与页面不匹配的样本（如 control 组用户看到了 new_page）
- 最终有效数据: **288,540 条独立用户记录**

### 2. 统计分析 ([`ab_stat_analysis.ipynb`](python/ab_stat_analysis.ipynb))
- 对照组与实验组转化率对比
- 卡方检验 + 比例 z 检验
- Odds Ratio 与 95% 置信区间
- 效应量（Cohen's h）
- 事后功效分析（Post-hoc Power Analysis）
- 所需样本量估算
- 时间趋势分析（日度 + 周度转化率变化）

---

## 核心发现

| 指标 | 对照组（旧版） | 实验组（新版） |
|------|--------------:|--------------:|
| 用户数 | 144,226 | 144,314 |
| 转化数 | 17,349 | 17,134 |
| **转化率** | **12.03%** | **11.87%** |

### 统计显著性检验

- **卡方检验**: chi2 = 1.66, **p = 0.1976**（alpha = 0.05 水平下不显著）
- **Odds Ratio**: 1.015（95% CI: [0.992, 1.038]），置信区间包含 1，无显著差异
- **转化率差值**: -0.16%（95% CI: [-0.39%, +0.08%]）
- **Cohen's h**: -0.0048（效应量可忽略）

### 功效分析

- **事后统计功效**: **25.28%**，远低于推荐的 80%
- **达到 80% 功效所需样本量（每组）**: **676,013**
- **当前样本覆盖率**: 仅为所需样本的 **21.3%**

这意味着即使观察到的差异是真实存在的，当前实验的样本量也**严重不足**以检测到它。

### 时间趋势

对 4 周数据的分析表明：
- 两组的转化率在整个实验期间保持稳定
- 实验组每周均略低于对照组
- 未观察到新奇效应（Novelty Effect）—— 实验组并未出现"先高后降"的模式
- 第 4 周数据量明显偏少（约 10K vs 45K），说明最后一周数据可能不完整

---

## 业务结论

新旧版落地页之间**无统计学显著差异**。

但更深层的问题是**统计功效不足**：
- 当前样本量（每组 144K）仅为所需样本量（每组 676K）的 **21%**
- 要达到足够的检测能力，实验需要运行约 **4.7 倍时长**或大幅增加流量

### 建议

1. **不应基于当前结果上线新版** —— 没有任何证据表明新版表现更好
2. **如果业务方认为微小的提升也有价值**，建议延长实验至每组约 67.6 万用户
3. **重新评估最小可检测效应（MDE）** —— 如果 0.16% 的差异在商业上没有实际意义，当前样本已足以得出"无实际差异"的结论
4. 考虑进行**细分分析**（新用户 vs 老用户、设备类型、流量来源等），以识别新版可能在特定人群中表现不同的情况
